# P2.6 Search Console / Measurement README

This folder contains the P2.6 measurement system for the Neuvago VNS SEO authority cluster.

## Files

| File | Purpose |
|---|---|
| `seo-measurement-plan.md` | Main measurement plan and decision rules |
| `search-console-launch-indexation-checklist.md` | Search Console setup and indexation checklist |
| `seo-weekly-review-template.md` | Weekly review template |
| `seo-vns-cluster-target-queries.md` | Query-to-landing-page map |
| `seo-vns-cluster-query-map.csv` | Spreadsheet-friendly tracking map |

## How to use

1. Deploy the current production site.
2. Submit `/sitemap.xml` in Google Search Console.
3. Inspect priority VNS pages.
4. Export Search Console data weekly.
5. Use the CSV and weekly review template to decide actions.
6. Do not create more pages until data shows a real gap.

## Recommended next work after P2.6

After 2–4 weeks of data:

1. Improve titles/meta for pages with impressions but low CTR.
2. Adjust internal links for query-page mismatch.
3. Strengthen product/how-it-works if device/stimulator terms appear.
4. Build new pages only when Search Console shows demand.
