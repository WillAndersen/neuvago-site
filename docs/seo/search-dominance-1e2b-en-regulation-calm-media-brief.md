# NEUVAGO SEARCH DOMINANCE 1E.2B — Media Brief

1E.2B does not require a new image asset before publication. The owner-lift requirement is satisfied with a locked media brief for the later image/video authority phase.

## `/learn/nervous-system-regulation`

### Diagram concept: “Demand → response → recovery → return”
- Show regulation as a dynamic cycle, not a calm/not-calm switch.
- Include a note that different organs and systems can respond differently.
- Avoid “sympathetic = bad / parasympathetic = good.”
- Avoid polyvagal-zone graphics presented as established whole-body diagnostics.
- Avoid an image that implies the vagus nerve controls the entire nervous system.

### Short video concept
60–90 seconds: “What nervous system regulation actually means.”
1. Regulation is not constant calm.
2. The ANS is organ-specific and coordinated centrally.
3. Recovery/return matters.
4. HRV and wearables are partial signals, not whole-system scores.

## `/learn/how-to-calm-your-nervous-system`

### Visual concept: “Lower demand before adding techniques”
A vertical, mobile-first six-step visual matching the page’s quick-step section:
1. reduce input;
2. slow comfortable breathing;
3. release obvious muscle tension;
4. use gentle movement if helpful;
5. make the transition predictable;
6. repeat what is tolerable and useful.

### Short video concept
60–90 seconds: “How to calm your nervous system without a viral hack.”
- lead with low-risk, repeatable steps;
- distinguish short-term settling from longer-term recovery;
- state that slow breathing can help some people without claiming a vagus “reset”;
- include a brief boundary that persistent/severe symptoms need appropriate care.
