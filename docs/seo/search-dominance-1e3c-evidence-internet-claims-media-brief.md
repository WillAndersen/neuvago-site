# NEUVAGO SEARCH DOMINANCE 1E.3C — Evidence vs Internet Claims Media Brief

## Primary reusable asset

Create a clean scientific-editorial evidence matrix titled conceptually:

**Common vagus claims: measured effect vs mechanism claim**

Six rows:
1. Slow breathing
2. Humming / singing
3. Gargling
4. Cold exposure / face cooling
5. Tapping / EFT
6. Neck pressure / carotid sinus

Four visual columns:
- claim
- what can be measured
- directness of vagus evidence
- safety / category boundary

## Visual language

Use the established premium Neuvago editorial style:
- warm neutral background
- black/charcoal type
- restrained scientific diagram language
- no wellness-mysticism iconography
- no glowing nerve, chakra, “reset button”, lightning bolt or magic pressure-point metaphor
- no fake clinical monitor traces
- no product render in the claim matrix

## Accuracy constraints

Do not:
- draw arrows that imply direct selective vagus activation from humming, gargling, tapping or cold exposure
- show one universal neck pressure point
- imply that HRV is a direct whole-vagus meter
- show cold exposure as a prescribed plunge protocol
- depict clinical carotid-sinus massage as a self-care technique
- borrow electrical-VNS electrodes or waveforms to illustrate behavioural claims

## Secondary visual candidates

1. **Claim ladder** — anatomy/plausibility → measured physiological effect → indirect autonomic marker → direct target engagement → clinical outcome.
2. **Cold-response complexity** — simple schematic showing that cold can affect heart rate, blood pressure, sympathetic and parasympathetic responses without a “reset” label.
3. **Voice/breathing separation** — humming as combined respiratory + vocal behaviour rather than a direct nerve switch.

## Image SEO later

Future assets should use descriptive filenames, alt text and captions that state the evidence boundary rather than the strongest popular claim.
